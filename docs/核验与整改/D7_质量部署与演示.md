## 2. 关键 D7 缺陷

1. **外部主路径都被 mock 或未运行（P0）**：CI `ci.yml:22-27` 明确 LLM_API_KEY 为空；GitHub 测试 `test_integrations_github.py:34-54` fake HTTP；Docker daemon 当前不可用。整改：在有凭据/服务时做受控 live run，证据脱敏，不把密钥写入日志。
2. **无浏览器 E2E（P1）**：D7 方案本身允许以演示手册替代，但完整 PRD要求真实前端交互；当前只能判部分。补 Playwright 登录→项目→任务→打卡→评价→贡献→推荐→周报→Agent→画像，桌面和 390px。
3. **演示手册与实现不一致（P2）**：`演示手册.md:44` 的 contested 与 API `disputed` 不一致；GitHub 回调/来源徽标实际缺失，手册 `:68-72` 写成可完整走通。应先修产品实现或明确“当前不可演示”。
4. **Docker 未传 GitHub 环境变量（P1）**：`compose.yaml:13-31` 没有 GITHUB_*，与 `.env.example:44-49` 和手册 `:18` 冲突。
5. **CI 没有迁移、compileall、PG 或安全边界门禁（P2）**：工作流只跑 pytest/build；不能证明 D7 方案中的部署和数据库要求。
6. **备份脚本未演练（P1）**：存在脚本不等于恢复成功；需真实创建、完整性检查、停止应用、恢复、登录/任务/审计回归。
